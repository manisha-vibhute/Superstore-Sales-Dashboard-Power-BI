# Superstore-Sales-Dashboard-Power-BI 
## Project overview 
Interactive Power BI Sales Dashboard created using the Sample Superstore dataset.
## Tools used 
- Power BI
- DAX
- Sample Superstore Dataset
##  Dashboard Features
  -  Total Sales
  -  Total Profit
  - Total Quantity
  - Sales by category
  - Sales by Segment
  - Top 10 States by Sales
  - Profit by Region
  - Sales by Ship mode
  - Monthly Sales Trend
  - Business Insights
